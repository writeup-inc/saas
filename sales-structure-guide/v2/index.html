01

第1営業部　人が主体

100万円を、100件

目標（月）

1億円

12月は2億円。100万円規模の受注を、100件積む計算です。

中小企業に、顧客単価100万円前後のAI SaaSを提案します。もう一つの役目は、100件分の勝ち方を残して、第2・第3営業部も使える型にすることです。

  • 提案5社
  • →
  • 受注1社
  • →
  • 紹介元A+のお客様

正直なところ

提案5社で、受注は1社。残りの4社は決まりません。それを最初から前提にしています。

平日の12:30と19:00に、AIの相棒社員「タケル」が、決まらなかった1件を聞きに来ます。愚痴でかまいません。話した内容は失注台帳に残り、次の提案の型になります。

最初に聞く人浦嶋 剛志さん（マネージャー）／土屋 慧介さん（リーダー）

02

第2営業部　人×代理店

売ってくれる会社を、増やす

10月の見込み

1億円

8月は7,000万円、9月は5,000万円。AIOは1社432万円です。

代理店・OEMパートナーと組んで売るチームです。自分で売り切らず、売ってくれる会社を増やします。1社の契約が大きいぶん、月ごとの数字は上下しやすい仕事です。

  • 候補
  • →
  • 返信
  • →
  • 契約
  • →
  • 共同商談
  • →
  • 受注

正直なところ

9月は、AIOのOEMを10社受注しました。ワークログ・インサイトのOEMも初受注です（1社216万円）。

10月の方針は、「ワークログで稼ぎ、Jマッチエンジンでリストを取る」。AIOは電話で追わず、AIで週2回以上、パートナーにメールが届く形にします。

最初に聞く人菅野 秀平さん（マネージャー）／降旗 一也さん・松井 友美さん（リーダー）

03

第3営業部　AIのみ

営業を、AIに任せ切る

100集客あたりの受注見込み

20〜30件

旗は「毎月100件売れるAI SaaSを、10サービス」です。

SaaSチームが8月17日に生まれ変わった営業部です。人が1社ずつ説得するのではなく、サービスと、そこへ連れてくる導線そのものを作って売ります。

  • 集客
  • →
  • 紹介動画
  • →
  • 説明会
  • →
  • 申込
  • →
  • 継続

正直なところ

10サービスの候補はありますが、全部が完成しているわけではありません。8月17日から、サービスごとに設計書を作り直しています。

いまの仕事は、導線つなぎです。アポが失注した企業へのメールや、LINEの友だち追加時の特典メッセージなどを整えています。

最初に聞く人木場 瑛穂さん／西村 果林さん／小松 咲さん

04

研修バード　研修＋バード

教えて、動かす

いま

約3,000万円

12月は5,000万円以上を目指します。

AI研修と、AIバード（AI導入・運用の代行、伴走支援）をセットで売るチームです。研修だけ、バードだけでなく、「研修＋バード」で売る形を目標にしています。

  • ウェビナー
  • →
  • AI研修
  • →
  • AIバード
  • →
  • 稼働月3,000時間

正直なところ

入口は2本です。AI TOWNとウェビナーでリードを集めることと、眠っている代理店の掘り起こしです。

バードは人が動く仕事なので、人が足りなければ売れません。A級バードを月30名自動で採用する計画で、採用も営業の一部です。

最初に聞く人川上 元さん（マネージャー）

05

AIインパクト　大型案件

1件で、月が変わる

1件の単価

1,000万円以上

通常の月は2,000〜3,000万円。目標は四半期3億円です。

コンサル・受託開発といった大型案件を扱います。いまは、2.5億円規模の案件がほぼ受注できていて、月1億円規模の数字が見えています。上下は激しいです。

  • リスト
  • →
  • リード
  • →
  • 提案
  • →
  • 受注
  • →
  • アップセル

正直なところ

1件にかける時間が長く、決まる月と決まらない月の差が出ます。だから目標は、月ではなく四半期で見ます。

リーダーの個人目標は「受注率100%」。まっさらなリストから、勝ちパターンを探りながら作っているところです。

最初に聞く人相澤 祥治郎さん／梅沢 勇貴さん（どちらもリーダー）

06

旧経コン　人×架電

月3万円を、毎日

受注のペース

1日2〜3件

月3,000万円、12月は1億円が目標です。

もとは経営コンサルティング局の営業チームで、補助金・助成金まわりの顧客基盤があります。いまは、月3万円のAI SaaSを軸に、受注を積み上げる役割です。

  • 架電
  • →
  • アポ
  • →
  • 商談
  • →
  • ヨミ
  • →
  • 受注

正直なところ

毎日の商談結果が、そのまま全員に見える形で残るチームです。9月30日は商談11件で、受注1件、見込みあり6件、失注4件でした。

失注の理由は、「決めきれない」「コスト」「多忙」に集まっています。理由が揃ってきたので、打ち手を絞り込める段階です。

最初に聞く人塩崎 万朔さん／杉山 正勝さん（経営コンサルティング局マネージャー）
