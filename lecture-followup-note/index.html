1無料のご提供

講演でお話しした、無料でお試しいただけるものを2つ並べました。まず使っていただき、合うものだけ先へ進めます。

おまかせ受電AI 無料モニター先着30社ほど

電話に出られないときの一次対応と、予約の受付をAIが担当します。モニター期間中は、初期費用・月額ともに0円です。

  • 費用初期費用 0円・月額 0円（モニター期間中）。期間・通話料・対象範囲は、ご利用開始のときにご案内します
  • お問い合わせ枠の状況は、会社のお問い合わせフォームに「おまかせ受電AI 無料モニター」とご記入のうえお尋ねください

しくみは3ページ目の「おまかせ受電AI」にあります。

Elliot（エリオット）

会議や商談の記録を、夜のうちにAIが読み、翌朝に「気づき」を届けます。Elliot自体の利用料は0円です。かかるのは、AIの利用料（API料金）の実費だけです。

  1. 昼会議・商談の記録がGoogleドライブにたまる
  2. →
  3. 夜Elliotが、その日の記録をまとめて読む
  4. →
  5. 朝気づきがSlack・LINE・メールに届く
  • 準備Googleドライブの設定のみ。AIの利用料（API料金）は、実費でご負担いただきます
  • 向いている会社会議や商談を録画・文字起こしして、記録がたまっている会社

Elliotの公開ページを見る

2ご提案

講演の最後にお話しした、一緒に取り組む2つの形です。共同開発は案件ごとに、OEMはサービスごとに条件を決めています。

考え方新しいお客様を探し続けるより、いまのお客様に、3か月ごとにひとつずつ新しい商材をご提案する。そのための道具を、まとめてご用意しています。

提案A　共同開発

「10社に売れて、月3万円ほどお支払いいただけそうだ」というサービスの案を、お持ちください。弊社が開発し、貴社が営業します。

  1. 貴社の案10社×月3万円ほどが目安
  2. →
  3. 弊社が開発つくる・更新する
  4. →
  5. 貴社が営業お客様への提案と対応
  6. →
  7. 貴社の商材に取り分は案件ごとにご相談

取り分や費用の分け方は、案件ごとにご相談します。

提案B　OEM（3か月に1商材）

弊社のサービスを、貴社のサービスとして取引先にご提案いただく形です。新規開拓ではなく、いまの取引先への2つめ・3つめのご提案に使っていただく形です。

おまかせ受電AI

電話の一次対応と、予約の受付をAIが行います。通話の記録が残るので、あとから内容を確かめられます。

  1. 電話が鳴るお客様から着信
  2. →
  3. AIが一次対応まずAIが電話に出る
  4. →
  5. 予約・よくある質問AIがその場で対応
    想定外の電話担当者へ転送
  6. →
  7. 全通話を記録あとから確認できる
  • 直販無料モニターを先着30社ほどで募集（1ページ目）
  • OEM売価・お客様への一次対応は貴社です。条件は「ご提案」のOEMの表のとおり
  • 向いている会社電話の多くが、予約・営業電話・決まった問い合わせの会社
  • 向かない会社電話がほとんど鳴らない会社。毎回、高度な専門判断が必要な電話が中心の会社

ワークログ・インサイト

パソコンの画面を約1分に1回記録し、AIが「どの業務に何時間かかっているか」を集計して、楽にする方法まで提案します。

  1. 記録画面を約1分に1回、自動で保存
  2. →
  3. 判定いつ・誰が・どの業務かをAIが判定
  4. →
  5. 集計業務ごとの時間を一覧に
  6. →
  7. 改善案AIツール・研修・開発・外部委託から提案
  • 直販月額1万円／1ID。対象はWindowsのパソコン（Macは未対応）
  • はじめ方全社一斉ではなく、1部署の数台からでも始められます
  • お見積り初期費用・契約期間は、お見積りの際に書面でご確認いただきます（金額は税別）
  • OEM「ご提案」のOEMの表のとおり

画面の記録は、1台あたり1年で約15万枚（目安）たまります。

ワークログ・ファクトサーチ

インサイトで貯めた画面の記録に、あとから日本語で質問して、過去の事実を確かめます。インサイトが「解釈」を毎週届けるのに対し、こちらは「事実」を、聞いたときに答えます。

  1. 質問する「あの案件はどうなっていた？」
  2. →
  3. AIが調べる貯めた記録をさかのぼる
  4. →
  5. 事実を答えるいつ・何が起きたか
  • 提供の形インサイトの追加オプション（別途有料）
  • はじめ方誰が何を質問できるかは、導入時に決めてから始めます
  • 料金ご利用の規模に合わせて、お見積りします

スーパーマネージャー

オンライン商談の前日から終わったあとまで、営業担当のとなりにAIの上司がつきます。会話はすべて記録として残ります。

  1. 前日お客様に事前にお話を聞いておく
  2. →
  3. 商談中営業担当だけに見える画面で助言
  4. →
  5. 15分ごと今の理解と、次に確かめる質問を整理
  6. →
  7. 終了後まとめと、次の提案のメール案
  • 対象オンライン商談が多い営業チーム。商談中の助言はGoogle Meetでご利用いただけます
  • ロープレ機能商談の記録から失注の理由カードをつくり、お客様役のAIと練習できます（オプション）
  • フォローメール人が確認してから送る形をおすすめしています
  • 料金ご利用の規模に合わせて、ご案内します

Jev（ジェブ）

文章を書くのではなく、渡された状況に対して「どれを選ぶか」だけを返すAIです。電話の振り分け、見込み客の選別、営業記録の緊急度の判定などに向いています。

  1. 状態を渡すたとえば、電話の内容
  2. →
  3. Jevが判断選択肢と、確信の度合い
  4. →
  5. 業務が進む転送・優先づけなど
  • 提供の形使う会社への導入支援と、貴社ブランドでのOEM
  • 条件個別にご相談のうえ、ご案内します

  1. 学ぶeラーニングで基本を身につける
  2. →
  3. 自分で自動化自分の業務にAIを当てはめる
  4. →
  5. 対面で深める必要な会社には訪問（別途）
  • OEM条件は「ご提案」のOEMの表のとおり。地方の会社へ対面でお届けする形です
  • 直販ご利用の人数に合わせて、お見積りします
