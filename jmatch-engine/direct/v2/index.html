01正直な前提

補助金は、1回ではなかなか通りません。

「この補助金、うちでももらえますか」への正直な答えは、1回の申請では難しいことが多い、です。理由は4つあります。

01

採択率

47.2%小規模事業者持続化補助金 第19回。16,576件の申請のうち採択は7,819件で、半分以上の8,757件は通っていません。

02

小さな会社ほど、書ける材料が少ない

体制・実績・数字で差がつきやすく、準備の質がそのまま結果に出ます。

03

何度も出して、通るもの

1回で通るとは限りません。直して再申請することも、よくあります。

04

加点項目の準備が要る

賃上げ計画や各種認定など、取得に2週間〜3か月かかるものもあります。申請を決めてから動くのでは、間に合わないことがあります。

採択率の出典：中小企業庁 2026年7月29日発表。制度や回によって異なります。

02考え方

だから、1回で決めずに、
何度でも申請できる会社になりましょう。

たとえば年10回、申請のチャンスをつかむつもりで動く。そのためには、見つけるのも、書くのも速くなければ回りません。

  2. 準備する加点項目を整える
  3. 書く御社がAIと書く
  4. 申請する結果を待つ

通らなければ、直して次の申請へ。書いたものは使い回せます。

10ご確認

申請の代行はしません。
申し込む前に、ご確認ください。

補助金は、通りますか。いくらもらえますか。

お約束はできません。審査するのは制度の事務局です。当社が支援できるのは、使えそうな制度を見逃さないことと、出てきたときにすぐ事業計画を準備できる状態をつくることです。

AIが、申請書を書いてくれるのですか。

いいえ。AIがつくるのは事業計画の土台です。制度ごとの提出書類を仕上げるのは御社ご自身か、有資格者の先生で、申請の代行も行いません。

ChatGPTでも、書けるのではありませんか。

文章を整える部分は書けます。ただ、実際に手が止まるのは書く前です。どの制度が合うかを毎週追うことと、答えやすい質問に分けて聞くこと。この2つをまとめてご提供します。

Claude Code とは何ですか。月額に含まれますか。

Claude Code は、米Anthropic社が提供するAIのツールです。Jマッチエンジンの「書く」はこの上で動きます。利用料は月額に含まれないため、御社で提供元と別途ご契約ください。初期設定は導入時にご案内します。

AIを使ったことがなくても、大丈夫ですか。

使ったことがない前提でつくっています。初期設定は導入時にご案内し、分からないときはAI家庭教師（月2時間まで追加料金なし）に聞けます。

月3万円は、高くありませんか。

月額に含まれるのは、毎週金曜の配信、AIとの計画書づくり、採択された計画書の見本、専門家相談（初回30分無料）、AI家庭教師（月2時間まで）です。成功報酬はいただかないため、採択額が大きくてもお支払いは変わりません。採択に至らなくても、書いた内容と書く力は会社に残ります。

外注したほうが、安いのではありませんか。

外注をやめてください、とは申しません。ご契約中は専門家をご紹介でき、事業計画の土台ができていれば、依頼する範囲も小さくなります。ただ、来年また出てくる制度を追い続ける人は、社外にはいないはずです。書く材料も、御社の中にしかありません。

作った事業計画は、融資にも使えますか。

使えます。補助金で聞かれることと、金融機関で聞かれることの多くは共通です。同じ土台から、融資相談の資料を組み立てられます。

顧問の税理士や行政書士に、資料を渡せますか。

はい。専門家へ相談するための整理資料として使えます。すでに顧問の先生がいらっしゃる場合は、その先生に渡す資料をつくる使い方もできます。

最低利用期間や、解約の条件はありますか。

最低利用期間・解約の条件・返金の取り扱いは、ご契約前に書面でお示しします。お申し込みの前に必ずご確認いただけるようにします。

  • 掲載している画面は開発中のイメージです。会社名・人名は架空です。制度名は表示のイメージとして掲げたもので、御社が対象になるかは公募要領と事務局の判断によります。

  • 補助金の多くは事業実施後の精算払いです。資金調達の相談先の審査や条件を、当社が保証するものではありません。
