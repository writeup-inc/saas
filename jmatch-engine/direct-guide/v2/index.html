    01DIAGNOSIS

    8つの質問で、
    いま使える制度が5〜6件見つかります

    所在地や業種、これからの投資予定など、8つの質問に答えるだけで、御社で使えそうな補助金・融資の候補が5〜6件出てきます。候補ごとに、締切・対象になる経費・次に確認することまで並ぶのが特長です。

    1. 入力は8項目だけ分かる項目だけでも大丈夫です。
    2. 締切と対象経費まで分かる「何に使えるか」「いつまでか」がひと目で分かります。
    3. 想定採択可能性は参考値「やや低い」でも申請できないわけではありません。最終判断は制度の事務局です。

    02WHY CONTINUOUS

    制度は、一度調べて終わりではありません

    補助金・融資・税制優遇は、国・都道府県・市区町村から年間を通じて次々に出てきます。必要になってから調べると、気づいたときには締切が過ぎている、ということも珍しくありません。

    1. 国・都道府県・市区町村で時期がばらばら今日なかった制度が来月始まることもあります。
    2. 去年あった制度が、今年は消えている名前も要件も、毎年のように変わるのが特徴です。
    3. 知る時点が違うだけで、出せる数が変わる継続して届けば、準備期間が残ります。

    03THE PROBLEM

    人の手で探して、人の手で書いていては、
    間に合いません

    見つけたときには、締切まで1〜2か月しかないこともあります。制度を探すのにも、白紙から事業計画を書くのにも時間がかかり、普段の仕事を止めずに両方をこなすのは簡単ではありません。

    1. 足りないのは「探す時間」毎週、国や自治体のサイトを見て回る余裕はありません。
    2. 足りないのは「書く時間」「自社の強みを書いてください」で手が止まります。
    3. やる気ではなく、時間の問題だから、この2つをAIで短くします。

    04OUR SERVICE

    だから、探すのも書くのもAIで。
    何倍も集めて、何倍も速く書きます

    探すほうは、国・都道府県・市区町村の補助金・融資・税制優遇をAIが集め、毎週金曜に御社へ届けます。書くほうは、AIが答えやすい質問に分けて聞き、答えが事業計画の土台になります。中身は、人の手で500社にご契約いただいている「Jコンサル」の支援です。

    1. 探す：AIが制度を集めてくる必要になってから探すのではなく、毎週向こうから届く仕組みです。
    2. 書く：御社がAIと一緒に書く白紙ではなく、答えやすい質問が順番に出ます。
    3. 中身は、500社が使う支援人の手で同じ支援を行う「Jコンサル」には、いま500社にご契約いただいています。その中身をAIで回せるようにしました。

    05FIND

    探すのはAI。
    毎週金曜の朝、御社に合う制度が届きます

    御社側で、国や自治体のサイトを毎週見て回る必要はありません。届いたときに「うちに関係あるか」を考えるだけです。気になった制度は「検討中」に入れておけば、締切の近い順に並び、あと何日かが大きく表示されます。

    1. 毎週金曜の朝に届く新しく見つかった制度の数と、締切が近いものの数がひと目で分かります。
    2. 補助金・融資・税制優遇まで国・都道府県・市区町村の分を、まとめて確認できるのが強みです。
    3. 「検討中」で締切を見逃さない「あと27日」のように、残り日数が大きく出ます。

    白紙からではなく、
    採択された見本を見ながら書けます

    08REUSE

    一度書いた内容は、
    翌年度の制度にも融資の相談にも使えます

    会社の概要、お客様、市場、強み、やること、効果。聞かれることは、翌年度の別の制度でも、銀行への融資相談でも大きくは変わりません。書いた内容は会社カルテに貯まり、次は書き足すだけで済みます。

    1. 今年の補助金の事業計画書
    2. 翌年度の、別の制度
    3. 銀行・信用金庫への融資相談
    4. 新規事業の計画・顧問の先生への資料制度ごとの書き足しは必要ですが、作り直しにはなりません。

    09WHAT REMAINS

    1匹の魚ではなく、釣り方が会社に残ります

    採択されても、されなくても、使い続けるうちに4つの力が会社に残ります。事業計画を作る力、強みを言葉にする力、効果を数字で示す力、そしてAIを実務で使う力です。補助金の準備が、そのままAIの実地研修になります。

    1. 事業計画を作る力何を聞かれ、どう答えれば伝わるかが分かります。
    2. 強みを言葉にする力「選ばれた理由」を、事実で語れるように。
    3. 効果を数字で示す力投資と売上の関係を、計算式で示せます。
    4. AIを実務で使う力補助金以外の、日々の仕事にも。

    10HUMAN SUPPORT

    それでも迷うときは、人がいます

    進めるうちにぶつかる壁は3つあり、それぞれに人の支援を用意しています。方向性に迷ったら、専門家に初回30分無料で相談。先に払うお金が要るときは、資金調達の相談窓口へ。AIで分からないときは、AI家庭教師に月2時間まで追加料金なしで聞けます。

    1. 方向性に自信がない → 専門家に相談補助金・税務・承継・採用・DXの専門家に、初回30分無料で相談できます。
    2. 先に払うお金が要る → 資金調達の相談窓口補助金の多くは後払いです。例えば300万円が採択されても、支払いは先です。銀行・事業ローン・ファクタリングの相談先につなぎます。
    3. AIで分からない → AI家庭教師ご契約中は月2時間まで追加料金なし。超えた分は1時間1万円（税別）。

    12FAQ

    よくいただくご質問

    商談でよくいただく6つのご質問です。気になるものを開いてご覧ください。

    補助金は、通りますか。いくらもらえますか。

    お約束はできません。審査するのは制度の事務局で、画面に出る想定採択可能性も参考値です。私たちが支援できるのは、使えそうな制度を見逃さないことと、出てきたときにすぐ事業計画を準備できる状態をつくることです。

    AIが、申請書を書いてくれるのですか。

    いいえ。AIがつくるのは事業計画の土台です。制度ごとの提出書類を仕上げるのは御社ご自身か、有資格者の先生で、申請の代行も行いません。

    ChatGPTでも、書けるのではありませんか。

    文章を整える部分は書けます。ただ、実際に手が止まるのは書く前です。どの制度が合うかを毎週追うことと、答えやすい質問に分けて聞くこと。この2つをまとめてご提供します。

    AIを使ったことがなくても、大丈夫ですか。

    使ったことがない前提でつくっています。初期設定は導入時にご案内し、分からないときはAI家庭教師（月2時間まで追加料金なし）に聞けます。

    月3万円は、高くありませんか。

    お支払いいただくのは情報の閲覧料ではなく、制度が出たときに事業計画をつくって動ける状態です。仮に1年間採択に至らなくても、事業計画をつくる力とAIを使う力は会社に残ります。

    作った事業計画は、融資にも使えますか。

    使えます。補助金で聞かれることと、金融機関で聞かれることの多くは共通です。同じ土台から、融資相談の資料を組み立てられます。
