Q無料と月3,000円は、何が違いますか。
A無料では、使える制度が毎週届き、自社が対象になりそうなものが分かります。月3,000円は、申請を取りにいく方だけのものです。過去の採択事例をもとにした御社の計画のたたきと、顧問の税理士・社労士へ渡す依頼書が出せるようになります。
Q月3,000円のたたきと、月30,000円の6つのエージェントは、どう違いますか。
Aたたきは、受け取るものです。6つのエージェントは、対話しながら御社ご自身が書き上げるためのものです。たたきは制度ごとに作り直しますが、エージェントと書いた6つは残り、来年も、銀行に出す資料の土台にも使えます。
QAIエージェントは、どこで動きますか。
AClaude Code 上で動きます。6つのエージェントが順番に問いを出し、答えた内容が書類の各欄に入っていきます。エージェントの中身（スキル）は毎月更新され、制度の改定や書き方の変化に追随します。
Q公募要領は、自分で用意する必要がありますか。
A出したい制度が決まっていれば、公募要領をそのまま登録していただくのが確実です。決まっていなければ、エージェントが最新の公募情報を検索します。ただし、要領の解釈と最終確認は御社ご自身か士業の先生にお願いします。
Q本当に自分で書けるようになりますか。
A書けるようになることを目指した設計ですが、お約束はできません。白紙の欄を埋める代わりに、答えられる問いにお答えいただく形にしています。手を動かしていただく必要はあります。
Q採択されることは約束されますか。
Aいいえ。審査するのは制度の実施機関であり、私たちではありません。採択率や受給額のお約束はいたしません。融資の承認についても同じです。
Q書いた内容を見てもらえますか。
A無料・ライト・スタンダードでは、制度に提出する書類の作成と添削は承っておりません。有資格者の仕事にあたるためです。エージェントが審査項目に沿って自己採点をお手伝いします。作成そのものが必要な場合は顧問契約をご案内します。
Q6つのエージェントはいつから使えますか。
A開発中です。開始時期が決まりましたら、順番待ちにご登録いただいた方へ個別にご連絡します。現時点で開始日をお約束することはできません。
Q顧問契約の士業は、こちらで選べますか。
Aご希望があればお伺いします。すでに顧問の先生がいらっしゃる場合は、その先生に渡す資料をつくる使い方もできます。担当する資格者、ご契約とご請求の相手、業務の範囲は、打ち合わせの場で書面にしてお示しします。
Q途中でやめられますか。入力した内容はどう扱われますか。
A解約の条件、最低利用期間、返金の取り扱い、お預かりする情報の範囲と保存・削除・外部送信の有無は、お申し込みの前に利用規約とプライバシーポリシーでご確認いただけるようにします。決算書そのものをお預かりすることはありません。
