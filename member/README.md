# LIGHT UP PARTNER BRIEFING

販売パートナー向けに、外部打ち合わせや新サービス企画から得た知見を、営業で使える形へ編集して公開するメディア。

公開URL: https://writeup-inc.github.io/saas/member/

## 公開前提

このディレクトリはPUBLICリポジトリとGitHub Pages上の公開領域であり、`noindex`はアクセス制御ではない。外部公開されても問題ない編集済み情報だけを置き、生ログや限定情報は置かない。

掲載しないもの:

- 打ち合わせの文字起こし・生ログ
- 相手企業名、担当者名、個人情報
- 未公開サービスの確定前情報
- 価格、契約、個別案件の条件
- 許諾のない直接引用や画像
- 根拠確認前の効果・成果表現

## 記事の追加

1. `member/<slug>/index.html`へ記事を作る
2. 「30秒で分かる要点」「何があったか」「分かったこと」「営業でどう使うか」「注意点」「次の一手」を確認する
3. 機密性・事実・外部公開可否を人が確認し、白石さんの承認を得る
4. `member/index.html`の新着一覧へ、公開日の新しい順でカードを追加する
5. `node tools/check-member.mjs`を実行する
6. モバイル375px、タブレット768px、デスクトップ1440pxで表示、リンク、フィルター、コピー操作、横スクロール、コンソールを確認する

未承認記事をインデックスへ掲載しない。元ログはこのリポジトリへコピーしない。
