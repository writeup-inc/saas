ISSUE 0054 MIN2026.09.10 / 注意・NG

30秒で分かる要点

「監視ではありません」と言うだけでは足りません。勤務態度の評価には使わないことを明言し、取得内容・閲覧範囲・保存・相談窓口を導入前に決めます。

THE RISK

説明不足そのものが、いちばんのリスクです。

会社側が業務改善を目的にしていても、現場には「誰が何を見られるのか」「評価に使われないか」という不安があります。その疑問を後回しにすると、正しいデータも集まりにくくなります。

見るのは人の良し悪しではなく、減らせる仕事です。勤務態度の評価には使いません。何を記録し、誰が見るかも、開始前に皆さんへ説明します。

BEFORE START

最低限、6つを合意する。

  1. 目的AI化候補の発見、反復作業の削減など、利用目的を一文にします。
  2. 対象対象部署、期間、端末、業務範囲を限定します。
  3. 取得内容何が記録され、何が記録されないかを実際の仕様で説明します。
  4. 閲覧権限誰が原データ・分析結果を見られるかを分けて決めます。
  5. 使わない用途勤務態度の評価など、目的外利用をしないことを明記します。
  6. 問い合わせ先現場が停止や確認を相談できる窓口を決めます。

RED FLAGS

この状態なら、開始を急がない。

一度立ち止まるサイン

  • 評価や査定に使う可能性が残っている
  • 取得内容を現場へ説明できない
  • 閲覧者が決まっていない、または広すぎる
  • 私用情報や機密情報の扱いが整理されていない
  • 停止・削除・問い合わせの運用が決まっていない

NG

「全部自動で判断できます」「誰がサボっているか分かります」と売らない。AIの分析は意思決定の候補であり、導入会社の責任者が目的に沿って確認します。
