05 / 13リストマスターとは

毎朝9時に、リストを作り
初回の連絡まで送ります。

  1. 条件を読むスプレッドシートの地域・業種・規模
  2. 探す複数のデータソースで企業を検索
  3. 除く廃業・重複を外してリストに
  4. 送る受信できないドメイン（約5%）を外し、初回のメールかFAX
  5. 報告する実績をメールで（Slack・Googleチャット可）
今朝の実行ログ自動で実行中
今日の条件（例）新潟県 システム開発 従業員10〜50名
  1. 9:00read_sheet条件を読み込む
  2. 9:01search企業を探す
  3. clean廃業・重複を除く
  4. verify宛先が届くか確かめる
  5. send初回のメールかFAX
  6. report実績をメールで報告
LIST MASTER右は説明用の画面イメージです。実際の表示とは異なります
話す言葉

お客様が最初に決めるのは、地域・業種・規模の条件と、送る文面です。文面はAIが用意し、独自のひな形の登録も可能。返信が来たあとは、お客様の側で話を進めます。あとは毎朝9時に、企業を探し、廃業や重複を除き、宛先を確かめてから初回のメールかFAXを送り、実績をメールで報告します。

毎朝「今日はどこに当てるか」を人に選ばせない設計です。確認の手間を残すと忙しい日に止まるため、条件を決めたら止まらないことを優先しています。
