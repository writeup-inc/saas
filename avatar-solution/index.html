  • A-01

    経営判断OS：セカンド

    重複

    会議の録画からAIが問いを選び、社長は声で答えるだけ。答えが条件ごと判断カードに残り、社長のいない会議でも社長の基準で決められます。

    経営判断OSの資料パックのA-01と同じページです

    →
    writeup-inc.github.io/saas/second-jev-edition/
  • A-02

    Jev 接客アバター

    LPの右端に案内役が立ち、訪問者が読んでいる区画に合わせて説明します。質問は音声でもテキストでも可能で、話し方は通常と五七五の切り替え式。

    →
    jev-avatar-lp.vercel.app/
  • A-03

    アバターニュース（仮称）

    NEW

    資料を入れると、社長の分身が5分前後の説明動画を作り、YouTubeへ自動で上げ、noteに記事を載せます。動画1本5,000円が基準の年間パックと月額プランを載せた申込ページです。

    →
    avatar-news-service.vercel.app/
  • A-04

    話すだけチャンネル（仮称）

    NEW

    社長が話した声から、資料・アバター動画・YouTube公開・SNS告知までを任せる、中小企業の経営者向けの紹介ページ。

    A-03と仕組みが近く、1つの商品にまとめるかは検討中です

    →
    writeup-inc.github.io/saas/hanasu-dake-channel/
