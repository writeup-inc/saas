01

FOR DECISION MAKERS

社長の判断

PostgreSQLのデータをAIから照会し、分析やレポート作成を支援する接続候補です。

向いている会社

  • 定型集計に時間がかかる
  • 自然言語でデータ確認したい
  • 読み取り用DBを用意できる

いったん見送る会社

  • 本番DBへ管理者権限で接続したい
  • 個人情報を無制限に返したい
  • クエリ負荷を監視できない

できること

  • 許可テーブルの構造を確認する
  • 読み取りクエリを実行する
  • 集計結果の意味を説明する

まだ確認できていないこと

  • 書き込み操作の有無
  • クエリ制限とタイムアウト
  • 採用実装のログ・保持方針

想定するデータの流れ

AIクライアント → 選定したMCPサーバー → 読み取り用DBまたはレプリカ。個人情報と本番負荷を分離します。

02

FOR IMPLEMENTERS

担当者の導入手順

本番へつなぐ前に、限定された検証環境で「読むだけ」の小さなタスクから始めます。

  1. 1

    使うMCPサーバーを特定する

    同じサービス名でも実装が複数ある場合があります。配布元、リポジトリ、更新履歴、ライセンスを確認します。

  2. 2

    ツールと権限を一覧にする

    読み取り・作成・更新・削除・送信を分け、最初に許可する操作を決めます。

  3. 3

    検証用アカウントで接続する

    対象データを限定し、CodexまたはClaude Codeの公式手順に沿ってサーバーを登録します。

  4. 4

    小さな依頼で結果を照合する

    検索や要約などの読み取りタスクを実行し、原本・操作ログ・権限範囲を確認します。

Codex

接続方法は実装特定後に確認

Codex CLIにはMCPサーバー管理機能があります。選定したサーバーの通信方式と起動コマンドを確認して登録します。

設定値：未確認

Claude Code

接続方法は実装特定後に確認

Claude CodeにもMCPサーバー管理機能があります。HTTPまたはローカル実行など、サーバー側の方式に合わせて登録します。

設定値：未確認
