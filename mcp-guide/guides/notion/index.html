01

FOR DECISION MAKERS

社長の判断

Notionに蓄積した規程、議事録、プロジェクト情報を検索・整理するための接続候補です。

向いている会社

  • 社内Wikiが育っている
  • ナレッジ検索を会話型にしたい
  • 定型報告の材料を集めたい

いったん見送る会社

  • ページ構造と権限が未整理
  • 原本確認なしで規程回答を自動化したい
  • 全社員の個人ページまで接続したい

できること

  • 許可ページの検索と読み取り
  • 複数ページの要約と整理
  • 記事・議事録の下書き作成支援

まだ確認できていないこと

  • データベース更新の対応範囲
  • 添付ファイルの扱い
  • 採用する実装の公式性

02

FOR IMPLEMENTERS

担当者の導入手順

本番へつなぐ前に、限定された検証環境で「読むだけ」の小さなタスクから始めます。

  1. 1

    使うMCPサーバーを特定する

    同じサービス名でも実装が複数ある場合があります。配布元、リポジトリ、更新履歴、ライセンスを確認します。

  2. 2

    ツールと権限を一覧にする

    読み取り・作成・更新・削除・送信を分け、最初に許可する操作を決めます。

  3. 3

    検証用アカウントで接続する

    対象データを限定し、CodexまたはClaude Codeの公式手順に沿ってサーバーを登録します。

  4. 4

    小さな依頼で結果を照合する

    検索や要約などの読み取りタスクを実行し、原本・操作ログ・権限範囲を確認します。

Codex

接続方法は実装特定後に確認

Codex CLIにはMCPサーバー管理機能があります。選定したサーバーの通信方式と起動コマンドを確認して登録します。

設定値：未確認

Claude Code

接続方法は実装特定後に確認

Claude CodeにもMCPサーバー管理機能があります。HTTPまたはローカル実行など、サーバー側の方式に合わせて登録します。

設定値：未確認
