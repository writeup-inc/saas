複数の方がお使いになる場合は、人数のぶんだけ積み上がります。たとえば3名がそれぞれ月40回・全機能で使う場合は、39,600〜43,200円です。

料金の前提

金額の計算に使っている、
4つの前提です。

  • 01
    1か月＝21営業日で計算しています平日のみで数えた日数です。祝日は差し引いていません。
  • 02
    商談は1回1時間で計算していますスーパーマネージャーは、商談の長さによって料金が上下します。
  • 03
    ご請求は、実際のご利用量にもとづきます1年間、初期費用と月額料金はかかりません。このページの金額は目安で、お使いにならなかった分の料金もかかりません。
  • 04
    為替によって変わる場合があります海外のサービスを使っている機能があるため、大きく円安が進んだ場合は金額が上下することがあります。その際は事前にご案内します。
