料金の前提

ご契約と、金額の計算の前提です。

  • 01
    ご契約期間は12か月です1年間、初期費用と月額料金はかかりません。途中でご利用を止めた場合も、Elliotの基本料金やJマッチのAIクローラーなど、毎日かかる料金は契約期間中ご請求します。
  • 02
    ご請求は、実際のご利用量にもとづきますこのページの金額は目安です。スーパーマネージャーは、AIが商談に同席しない限り料金はかかりません。
  • 03
    「1日◯回」は、平日だけで数えています1か月＝21営業日（祝日は差し引いていません）で計算しています。Elliotの基本料金とJマッチのAIクローラーは、土日もかかるため30日で計算しています。
  • 04
    商談は1回1時間で計算していますスーパーマネージャーは、商談の長さや会話量によって金額が前後します。
  • 05
    為替によって変わる場合があります海外のサービスを使っている機能があるため、大きく円安が進んだ場合は金額が上下することがあります。その際は事前にご案内します。
